# ULTRON — primary task per screen

The UX-laws rule: before laying a screen out, name who uses it and the one thing they came to do.
Everything else on the screen is secondary and ranks below it (Hick, Occam, Visual hierarchy).

| Screen | Who | Primary task (one sentence) | Primary action |
|---|---|---|---|
| Home (Operator view) | Control-room operator | See at a glance which machine needs attention right now. | Open the alarm / machine |
| Maintenance › Problems | Reliability engineer | Work an open problem from first sign to a checked repair. | Start a case / open a case |
| Assets › machine Overview | Operator | Read the machine's live state on its drawing. | Open the part that is not Normal |
| Assets › Diagnosis | Engineer | Find which sensor and part are causing the machine's condition. | Acknowledge / create work order on a problem |
| Assets › Prognosis | Planner | See what will need work next and how long is left. | Plan the work |
| Assets › Analysis | Engineer | Understand why one problem is happening and what it affects. | Mark the cause / send to maintenance |
| Assets › Sensors | Instrument technician | Check every sensor's reading quality and wiring. | Open a sensor's history |
| Maintenance | Maintenance planner | Decide and schedule the next jobs. | Plan a job / open a work order |
| AssetIQ | Anyone | Ask a question about the plant and get a direct answer. | Send the question |
| Devices | Instrument / IT technician | Find where sensor data stops reaching ULTRON and fix the link. | Connect a data collector |
| Configure | Plant administrator | Add and edit plants, machines, people and settings. | Add plant / machine |
| Configure › Onboarding | Plant administrator | Bring a new plant in from its documents, step by step, to a working plant. | Next step → Create the plant |
| Simulation | Trainer / demo lead | Start a fault on a machine and watch the real pages respond. | Start a fault |
| Sign in | Anyone | Get into their plant. | Sign in |
